Solar System Calculator

Qadam 1: Load aur panel

Apna load aur backup ke ghante likhein, phir panel chunein.

Qadam 2: Solar chunein

Solar ka 20% loss minus karne ke baad jo bachta hai wo load ke qareeb hona chahiye. Thora upar neeche theek hai, zyada nahi.

Qadam 3: Battery

Voltage load se khud lagta hai. Row par click karke battery chunein.

Qadam 4: Charging

Charging ka load aap baad mein bhi badal sakte hain, baqi sab wahi rahega.

Qadam 5: MPPT aur strings

Ek string maximum 450V. Baqi MPPT khali reh sakte hain.

Natija

Formula: Battery chahiye = Load x Ghante / (1 - loss). Backup = Battery Wh x (1 - loss) / Load. Charging = Battery Wh / (Charging load x (1 - loss)).
